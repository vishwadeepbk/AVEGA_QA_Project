1. Application Chosen and Why
Application: OrangeHRM Demo Website
**URL: https://opensource-demo.orangehrmlive.com/web/index.php/auth/login**
Why this application?
The OrangeHRM demo application was chosen because:

It is a publicly available web application for automation practice.
It provides a realistic login module that is commonly used in Selenium interview questions.
It supports both positive and negative login scenarios.
The application is stable and does not require any local setup or database configuration.

3. Test Scenarios Covered
Positive Scenarios

Verify successful logout after login.
Negative Scenario
